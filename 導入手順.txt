市区町村制覇アプリ：地形・地名・細い市区町村境界版

【事前に必ず行うこと】
・iPhoneなど、普段使っているアプリから「JSONを書き出す」でバックアップし、保管してください。
・GitHub Desktopで、未コミットの変更がないことを確認してください。
・公開前の最後の状態に戻せるよう、現在のGitのコミットを残してください。

【変更するファイル】
・app.js                          地形タイル・地名タイルの追加、色分けと境界描画の調整
・index.html                      地図の説明文だけ更新
・style.css                       地形レイヤー合成と背景色を追加
・tests/map-japan-only.test.cjs   地図の自動テストを更新

【導入方法】
1. ZIPをWindowsで「すべて展開」する。
2. GitHub Desktopで municipality-conquest を開き、Repository > Show in Explorer を選ぶ。
3. 展開した app.js、index.html、style.css をリポジトリ直下の同名ファイルに上書きする。
4. 展開した tests フォルダ内の map-japan-only.test.cjs をリポジトリ内の tests フォルダに上書きする。
5. GitHub DesktopのChangesには上記4ファイルだけが表示されることを確認する。
6. Summaryに "Add Japan terrain relief map" と入力し、Commit to main、Push origin の順に実行する。

【導入後の確認】
・PC／iPhoneのSafari／iPhoneホーム画面版で、地図に地形・市区町村名が表示される。
・北海道などで山地の色・陰影と市町村の細い境界線が見える。
・都道府県の切り替え、全国表示に戻す、地図からの記録編集が従来通り使える。
・訪問済み件数・制覇率・訪問記録は更新前と一致する。
・JSON書き出し・読み込み前の復元ボタンが引き続き表示される。
・海外の世界地図タイルは使用していない。ただし国土地理院タイルの提供範囲や
  ズームによっては、日本周辺の地理情報が見える場合がある。

【補足】
・元の行政区域データ（2021年版、0.1％簡略化）そのものは変更していません。
  線を細くし、描画時に形が省略される量を減らしています。
・地形タイルの表示はインターネット接続と国土地理院の配信状況に依存します。
  配信に失敗しても、従来の行政区域データが正常に取得できれば境界の表示は残ります。
・データ利用出典：国土地理院「地理院タイル」
  https://maps.gsi.go.jp/development/ichiran.html
  色別標高図の海域部は海上保安庁海洋情報部の資料を使用して作成。
・第三者の「まぷすた」画面を転載したものではなく、公開地理データを使って近い表現を目指したものです。
・Node.js環境がある場合の自動テスト： node --test tests/*.test.cjs
・ブラウザ・iPhone実機での表示確認は開発者が行ってください。
